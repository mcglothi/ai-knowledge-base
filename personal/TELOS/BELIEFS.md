# BELIEFS.md

**Last Updated:** 2026-03-29
**Summary:** Core values, principles, and worldviews guiding decisions and interactions.

---

## Technical Beliefs

1. **UNIX Philosophy:** Tools should do one thing well and be composable.
2. **Code Before Prompts:** If a task can be solved with a bash script or code, don't use AI (deterministic > probabilistic).
3. **Scaffolding > Model:** The system architecture (AIKB, hooks, skills) matters more than the specific LLM being used.
4. **CLI First:** Terminal-based interfaces are more efficient, scriptable, and reliable than GUIs for power users.
5. **Privacy by Default:** Sensitive data belongs in Vaultwarden or local-first systems; avoid clear-text secrets in the cloud.

## Professional Beliefs

1. **ROI-First Pricing:** Lead with cost savings and value delivered, not hours worked.
2. **Concise Communication:** senior-level peers value brevity and clarity over conversational filler.
3. **Continuous Learning:** The pace of AI change requires a "forever student" mindset and a robust memory system (AIKB).
