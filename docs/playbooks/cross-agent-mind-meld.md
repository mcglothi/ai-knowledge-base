# Cross-Agent Mind-Meld Playbook (v2)

## When to Load
- Tasks require coordination across multiple agents or reconciliation of differing feedback.

## Workflow
1. Gather each agent's recommendation and rationale.
2. Normalize into: decision, risks, improvements, action items.
3. Merge non-conflicting items first.
4. Document deliberate tradeoffs for conflicting advice.
5. Send concise follow-up IMs if clarification needed.

## Deliverable Pattern
- Consensus items
- Conflicts + chosen resolution
- Next execution steps
